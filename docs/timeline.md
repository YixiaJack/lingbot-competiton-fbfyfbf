# 时间线

从初赛到决赛结束的主要节点。时间都是北京时间。

## 初赛（10 月中旬 – 10/26）

在 RoboTwin 2.0 仿真的 50 个双臂任务上微调 LingBot-VLA 2.0，详见 [prelim/](prelim/README.md)。

| 时间 | 事件 |
|---|---|
| 10/19 前后 | 在我的算力上搭好环境；集群排队很满，改用可抢占分区，训练改成随时可续训 |
| 10/20–10/21 | 主线训练 40k 步（4 × B200） |
| 10/21–10/22 | 按官方增强白名单做强数据增强，从主线续训和从头训两条线对比 |
| 10/22–10/25 | 从头训 22k + 续训 8k；DINOv2 融合实验；把评测移植到另一台 AMD 服务器上并行跑 |
| 10/23 | 主办方答疑明确专家尝试最多 5 次，评测脚本随之修正，之前的数字偏乐观 |
| 10/26 24:00 | 初赛提交截止，提交 22k + 8k；官方复测 clean 82.22 / randomized 57.26，平均 69.74，进入决赛 |
