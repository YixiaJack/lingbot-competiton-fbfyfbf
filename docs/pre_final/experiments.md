# 赛前与开赛初期的实验

> 11/11–11/15 我们做的几组实验。前三组在我的算力（Slurm）上、RoboTwin 2.0 仿真里，用来在拿到真机之前检验 [赛前技术方案](plan.md) 里的几条可选做法；后两组在开赛后做，服务于开发机上的真机训练和任务 3 的推理（集群上复现训练、官方真机示范上的离线分析，加上一部分仿真）。每组的代码、设置和完整结果在 `experiments/` 下各自的 README 里，这里是总览。
>
> 数字都带着条件写：几个场景、什么起点、什么输入。仿真结果的起点大多是初赛时我们在 RoboTwin 上训好的 LingBot-VLA 2.0 6B 权重（从官方底座从头训 22k 步、再续训 8k 步，下文叫“22k+8k”），不是现场微调的官方 6B。

## 术语

| 词 | 意思 |
|---|---|
| VLA | 视觉-语言-动作模型：输入相机画面和文字指令，直接输出机械臂动作。这里就是 LingBot-VLA 2.0 6B |
| 首次靠近 | 机械臂第一次伸向的是哪个物体。决赛任务 1、2 的识别分只看这一次；仿真里用“夹爪中心第一次进入某个候选物体初始位置 10 cm 内、且比开局靠近了 4 cm 以上”来判定，是我们的代理指标 |
| 画框提示 | 在头顶相机画面上画白框（目标物）和橙框（目的地）再交给 VLA；框由本地小检测器按指令选出，没把握就不画 |
| boxgrasp | 画框的一种变体：夹爪合上（抓住目标）以后撤掉白框，橙框保留 |
| harness | 任务 3 外面的一层调度程序：判断机器人处在哪个子任务，给 VLA 发这个子任务的固定指令；VLA 生成的动作原样执行 |
| 配对评测 | 所有条件用同一批场景和同一组策略噪声种子，逐场景比较 |

## 各实验

### yolo_target_prompt：3 色方块代理实验（11/11，暂停）

最早的一版“画框有没有用”实验：RoboTwin 里 3 个彩色方块和 3 个彩色盘子，比较纯文本、画框、把框坐标写进指令三组，并留出 3 种“方块 × 盘子”组合测泛化，计划 510 回合配对评测。11/12 凌晨暂停，当时只完成了场景和 BF16 推理两项冒烟测试、采到 19/120 条示范。暂停的原因是方块和盘子代表不了决赛的果蔬、化妆品和透明收纳盒。

它留下的是代码：画框 / 写坐标、规则解析指令、按“置信度 + 领先第二名”选框、没把握就退回纯文本、配对种子和首次靠近判据，都原样带进了 real_detector；`patches/` 里是我们初赛代码树相对官方代码的全部改动。详见 [README](../../experiments/yolo_target_prompt/README.md)。

### real_detector：决赛物品检测器与画框提示（11/12–11/14）

按决赛物品清单在 RoboTwin 里重搭了三个任务的场景（摆放规则和哪些是我们的假设见 [SCENE.md](../../experiments/real_detector/SCENE.md)），训练了认全 59 类的 yolo11s，再用任务 1 的 200 条专家示范训了纯文本组和 50% 画框组。仿真里检测和选框几乎满分（mAP50 0.995，按指令选框 331/331），但训练和验证共用同一批 3D 模型，这只说明链路是通的。60 个场景的配对评测里，画框组拿到 YOLO 框时首次靠近比纯文本组高 16.7 个点（区间 +3.3 ～ +30），过了队里定的 +15 个点门槛；成功率只多 5 个点；画框组拿不到框时低 6.7 个点（区间 −18.3 ～ +5，不显著），“不加提示时不变差”这一条没有定论。

11/14 拿到官方 647 条真机示范后，用首末帧差分自动造了真值（每条结束时机械臂回原位，只有目标物变了位置），直接测这个只见过仿真图的检测器：任务 1 目标认对 33%、任务 2 8%，蓝盘、紫盘几乎全被叫成白盘，黄纸团一个都没检出。详见 [README](../../experiments/real_detector/README.md) 和 [real_check](../../experiments/real_detector/real_check/README.md)。

### task_routing：任务路由下 VLM 怎么训（11/12 起，未完成）

决赛只有三个固定任务、推理时任务已知，于是试了“动作专家每层 MoE 给每个任务复制一个路由器”，在此基础上比较 VLM 的 8 种训法（冻结、全量、共享 LoRA 和每任务 LoRA，LoRA 各有 3 种插法）。路由补丁不开时和原版完全一样，8 组的第 0 步都和底座等价，冒烟测试全部通过。正式训练只用 B200，排队很慢，到决赛开始前没有任何一组的评测结果，所以没有对比结论。决赛训练也没有用任务路由。详见 [README](../../experiments/task_routing/README.md)；设计依据见 [赛前技术方案](plan.md) 第 7.8 节。

### hpc_replica：在集群上复现开发机训练（11/14）

开赛后开发机 8 卡一直在训练，重启前要用的改动先在集群上验证。我们复现了开发机的代码、环境、底座和数据（条数、帧数完全一致），验证了“从存档加载 + 新输出目录 + 不恢复 dataloader 位置”的换数据重启：步数从 11 接着走、学习率不变、loss 连续，瘦身后的存档能被开源推理代码严格加载。时间拆分显示图像增强不增加耗时，teacher 约占 14%，`DistributedMuon` 优化器约占 22%（2 × H200 上，只看比例）。详见 [README](../../experiments/hpc_replica/README.md)；决赛中的重启做法见 [docs/final/training.md](../final/training.md)。

### sweep_harness：任务 3 的子任务调度（11/14–11/15）

仿真部分在 RoboTwin 里搭了清扫场景，比较由 LLM 自己划分子任务（V1）和固定 5 步、LLM 只判断进度（V2）。离线判断测试里两版对齐标签后分别为 0.95 和 0.92；VLA 训练 11/14 下午停掉，闭环评测没跑。

真机部分从官方 216 条任务 3 示范里归纳出固定的 4 段（抓取 / 扫 / 倒 / 归位），216 条逐条核对没有例外；同一份切分规则生成训练数据，也决定推理时发给 VLA 的指令。在真机示范上，LLM 判断当前段的逐次准确率 0.949；它总在手臂真正回位前 0.5–4.8 s 说“完成”，所以停止改成“两臂静止 2.5 s 且夹爪松开”。真机回合里，只看画面的版本在扫和倒之间来回切，只看夹爪读数的版本会被“夹在簸箕边沿”卡住，这些问题和后续改法记在 [PROPRIO.md](../../experiments/sweep_harness/PROPRIO.md)。详见 [README](../../experiments/sweep_harness/README.md)；决赛中的版本演化见 [docs/final/task3_harness.md](../final/task3_harness.md)。

### 显存：一直没有在 5080 上实测

推理机是 RTX 5080（16 GB），real_detector 原计划把推理服务限制在 15 GB 跑 10 回合，11/13 从流程里去掉了。现有的显存记录都不是在 5080 上测的：yolo_target_prompt 的 BF16 冒烟测试峰值 12.08 GiB（A100 / H100），task_routing 冒烟测试在 15 GB 上限下峰值约 12.1 GiB（B200，含 3 个任务路由器）。

## 哪些迁移到了真机，哪些没有

**迁移了的：**

- **画框提示的整套做法**（real_detector → 决赛推理端的 yolocue）：白框目标、橙框目的地；规则解析指令，不用语言模型；目标置信度够高且领先同类第二个框 0.15 才画，没把握就给原图；训练数据一半画框、一半原图；夹爪合上后撤掉白框。真机版把“夹爪合上”从读数改成了夹爪**指令**，因为大物体（如南瓜）合上时读数只从 0.90 降到 0.83。见 [docs/final/inference.md](../final/inference.md)。
- **差分真值**（real_check）：312 条官方示范的目标物框，成了之后各版检测器的验收集。
- **任务 3 的 4 段切分**（sweep_harness）：所有决赛训练里的任务 3 数据都按它切成子任务，推理端的 harness 用同一份子任务定义（[docs/final/data.md](../final/data.md)）。harness 的对话管理、停止规则和推理机接入方式也沿用了下来。
- **换数据重启的做法和存档清理**（hpc_replica）：决赛中每次换列表重启都这样做。

**没有迁移的：**

- **仿真训练的检测器**：真机上目标认对只有 33% / 8%。它只见过我们找来近似的 3D 模型和仿真渲染（训练和验证共用同一批模型，仿真里的满分说明不了泛化）；真机相机下紫盘偏灰或偏粉、蓝盘很浅；真机上还有仿真里没有的物体（黄纸团）。开赛第一天就改成用开放词汇模型 LocateAnything-3B 自动标注官方示范、在真机图上重训 yolo11s，再人工核对逐版迭代（[docs/final/yolo.md](../final/yolo.md)）。
- **仿真里的定量结论**：画框 +16.7 个点是在“仿真 YOLO 几乎全对、只测任务 1、初赛模型、框整局不撤”的条件下得到的，真机上没有做同样的开 / 关对照。
- **仿真清扫场景和其中的 V1 / V2 对比**：仿真布局是我们猜的（簸箕固定左臂拿），真机示范是两种镜像布局、先抓的手拿簸箕；真机用的是固定划分，划分方式直接从真机示范里归纳。
- **任务路由**：没有结果，决赛没用。
