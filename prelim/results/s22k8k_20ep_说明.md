# 22k+8k 评测结果：每个任务 20 回合（q100_s22k8k_8k）

- 模型：`strong_scratch22k_cont8k/checkpoints/global_step_8000/hf_ckpt`。由 lingbot-vla-v2-6b 先用 clean 数据训练 22k 步，再用强增广 + Fourier + 腕部相机丢弃 + 任务均匀采样续训 8k 步。
- 环境：我的算力，NVIDIA GPU（A100 / H100 / L40S），RoboTwin `13c3c47`（官方指定版本）+ CuRobo，FP32，执行长度 50，clean 归一化统计。
- 指令口径符合主办方答疑：clean 用 seen 指令，randomized 用 unseen 指令。100 个结果文件里的指令类型都核对过，clean 全是 seen，randomized 全是 unseen。
- 专家规则（答疑第 13 条）：专家每个场景最多试 5 次；5 次都失败时，照样评测模型并计入次数。
- 每个任务 20 回合，seed 0，种子从 100000 起。
  - 前 7 回合就是之前 7 回合那次评测（q50x7_s22k8k_8k）的结果。
  - 第 8–20 回合是从断点接着跑的，种子序列和一次跑完 20 回合完全相同。

## 数据说明：有 7 个任务被两个评测进程同时跑过

评测池偶尔会让两个进程同时接手同一个任务。它们从同一个断点续跑，跑的是同样的种子，结果写进同一个日志和同一个进度文件。受影响的回合如下：

| 设置 | 任务 | 受影响的回合 |
|---|---|---|
| clean | adjust_bottle | 第 9–11、14、15、17 回合 |
| clean | place_empty_cup | 第 6、7 回合 |
| clean | place_mouse_pad | 第 14、17–20 回合 |
| clean | stack_bowls_three | 第 19 回合 |
| randomized | beat_block_hammer | 第 17、18、20 回合 |
| randomized | move_playingcard_away | 第 1、4、7 回合 |
| randomized | place_object_stand | 第 3 回合 |

处理办法：

- **还原正式序列**：我用两条线索还原出正式计入的那条回合序列。一是日志里每次续跑时记下的断点（第几回合、成功几次、下一个种子）；二是每回合后打印的累计成功数。还原后，每个任务 20 回合的成功次数都和进度文件里的正式计数一致，前 7 回合也和之前 7 回合那次一致。
- **同一种子两边结果不同**：只有 2 处，正式计入的都是成功，也就是最后写进度文件的那一边。
  - clean place_mouse_pad 第 18 回合（种子 100017）：一边成功、一边失败。
  - randomized move_playingcard_away 第 7 回合（种子 100007）：同上。
- **日志行被覆盖**：有 2 个回合的记录被另一个进程覆盖掉了，结果和种子由前后两回合推出，两回合都是成功。
  - clean adjust_bottle 第 12 回合（种子 100022）。
  - clean place_mouse_pad 第 13 回合（种子 100012）。
- **步数**：两个进程同时在跑的回合，输出混在一起，`每回合明细.csv` 里"用了多少步"一栏留空。

## 文件

| 文件 | 内容 |
|---|---|
| `汇总.csv` | 每个任务 clean / randomized 的 20 回合成功次数和成功率，以及第 1–7、第 8–20 回合的拆分；最后一行是合计 |
| `每回合明细.csv` | 2000 个回合，每回合一行：种子、成功或失败、用了多少步、步数上限、这一回合前跳过了几个种子、是否属于"专家 5 次都失败后照样评测"的回合、备注（上面几种特殊情况） |
| `原始日志/<setting>/eval_logs/<任务>.log` | 评测客户端的完整输出 |
| `原始日志/<setting>/inference_logs/<任务>.log` | 推理服务日志 |
| `原始日志/<setting>/eval_results/<任务>/_result.txt` | RoboTwin 写出的结果文件（含指令类型） |
| `原始日志/<setting>/state/<任务>.json` | 断点续跑用的进度记录 |
| `原始日志/<setting>/<任务>.result` | "成功次数 总次数" |

`原始日志` 是 10/24 19:55（北京时间）从集群复制的。那时评测已经在跑 40 回合：clean 大多数任务已经跑完 40 回合，randomized 有几个任务也已经开始跑第 21 回合以后。所以日志、`.result` 和 `state` 里会有 20 回合以后的内容，本文件夹的表格只统计前 20 回合。
